| # | 修正 | この修正が新しく主張すること |

## 2. 記録すべき誤りの訂正

R2 spec §1 の F2 行「成立しない実行は pending がその記録」は orchestrator の転記誤り（本文はそう述べていない。2 観測者 — cursor と persona 座席 — から計 4 件の指摘）。R2 spec は投函後不変のため上書きせず、本書のこの節を訂正の記録とする。正しくは R2 時点で「成立しない実行に記録は構成されず、痕跡の保持は backlog」であり、R3 で第 2 裁定 ② により「最小の痕跡を残す」へ変わった。

## 3. R3 で advisory（(c)・queue）扱いのもの

R2 までの (c) を引き継ぐ。追加: 無人 consumer（`kairos_verdict.py`・agent guard track）の移行は参考値化の実装時に §6 の改名/注記項目と併せて扱う（Pragmatist R2）／座席判定の導出規則の既定を条文でなく backlog に置く形は維持（cursor R2 P2）。宣言済み Open Unknown 2 件（批准 07-31）の再指摘は (c)。空返答型 APPROVE は枠を問わず数えない（既宣言の再確認 — R2 で codex に発生、41 字）。
